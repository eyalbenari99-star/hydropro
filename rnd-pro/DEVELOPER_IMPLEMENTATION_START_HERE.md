# HydroNexis-AI R&D & Planning — Developer Implementation Start Here

This source package is embedded inside the standalone `index.html` developer handoff. Use the **Developer Handoff** button in that HTML to download this package.

## Included

- High-end animated Executive Cockpit and Professional Engineering Studio
- TypeScript/React source and compiled browser bundle
- 2D scene engine with image selection, movement, resizing, rotation, snapping, measurement, layers, and history
- Nexi review fixtures, assumptions, evidence, risks, confidence, and governed change previews
- FastAPI contracts and service foundation
- PostgreSQL migrations for engineering projects, immutable revisions, approvals, overrides, evidence, calculations, notifications, and governance
- Frontend and backend tests
- Motion/design system, architecture, deployment, validation, and master specification documents
- DXF-first CAD interoperability foundation and 3D component assets

## Recommended implementation order

1. Read `docs/master-spec/HYDRONEXIS_RND_PLANNING_NEXI_ENGINEERING_MASTER_SPEC_v1.0.md`.
2. Read `docs/DEVELOPER_REVIEW_GUIDE.md` and `REVIEW_PACKAGE_MANIFEST.md`.
3. Run the frontend and backend test suites.
4. Apply the PostgreSQL migrations in order.
5. Integrate shared EIOS authentication, roles, project permissions, object storage, notifications, and audit services.
6. Replace review fixtures with authorized company services and validate every engineering calculation by discipline.
7. Preserve mandatory human approval for safety-critical, legally regulated, financial, Approved, and Issued actions.

## Important boundary

The included application is a working developer-review foundation, not a licensed CAD/BIM engine and not an engineering certifier. Production release requires security review, licensed format components where applicable, discipline-specific validation, qualified engineer approval, and controlled rollout.
